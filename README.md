# About Light Saml

[![Run tests](https://github.com/litesaml/lightsaml/actions/workflows/run_tests.yml/badge.svg)](https://github.com/planningsagenda-systeem/lightsaml/actions/workflows/run_tests.yml)
[![Latest Stable Version](https://poser.pugx.org/planningsagenda-systeem/lightsaml/v/stable)](https://github.com/planningsagenda-systeem/lightsaml/releases)

Light Saml Implements basic SAML 2.0 data model classes, serialization/deserialization to/from xml with XML security and
certificates support, and message encapsulations to bindings. Covered with unit tests.
